Fufa is an omnichannel CRM. Customer conversations from channels such as WhatsApp and website chat land in one inbox.

This site is the public documentation. Each page is markdown, and the build also publishes [`llms.txt`](/llms.txt) so answer engines and coding agents can read the same pages.

Guides are added here as product features ship.
